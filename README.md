# muse-onelaugh1126n-entry

> I put my phone on airplane mode, and it has already seen more of the world this year than I have.

Travel envy, directed at the device in your own pocket. This repository contains the complete One Line, One Laugh submission and the program that tells the joke.

## Running the program

Execute `main.py` with Python 3. Standard library only, no network access, fully deterministic: the joke line and a newline in `entry.txt`, placed under `MAKEFUN_OUTPUT_DIR` if set and under `/output` otherwise.

## Selection notes

This brief is the purest of the batch: one funny line, in one breath, whose laugh comes from a turn or one exact word rather than explanation or a familiar meme. A dead houseplant replaced by a judging fake strolled where it should have snapped. A gym, a mirror and a cake needed three props. The phone in airplane mode needs one object and one comparison, and the envy hiding inside that comparison — the device out-travelling its owner without leaving the owner's hand — is what makes it funny instead of merely cute.
